2. 熟悉 Android/iOS 开发，具备跨端开发经验（Flutter/RN 等）；
3. 具备良好的架构设计、性能优化及问题排查能力；
4. 具备较强的责任心、自驱力及团队协作能力；
5. 有大型 App、游戏开发或互动类产品经验者优先；
