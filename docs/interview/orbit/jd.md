## 原文

**公司背景**：澳洲金融科技公司，产品已盈利（最老的有 10 年），成熟不需融资。拿母公司最好的资源和市场体系，重构做 AI 方向。深圳新建团队。

### 岗位职责

1. 使用 React Native 开发高性能、可维护的移动端应用
2. 参与 App 架构设计、组件抽象、性能优化及工程化建设
3. 负责移动端复杂业务场景开发（交易、实时数据、消息交互等）
4. 参与跨端技术方案设计，提升开发效率与代码复用能力
5. 与后端、产品、设计高效协作，推动需求高质量交付
6. 持续优化移动端用户体验、稳定性及性能表现

### 技术要求

1. 扎实掌握 JavaScript / TypeScript / HTML / CSS
2. 熟悉 React Native 技术栈（生命周期、通信机制、性能优化）
3. 熟悉 React 生态（Hooks、Context、状态管理）
4. iOS / Android 原生开发经验或理解（优先）
5. 熟悉移动端工程化（打包、发布、CI/CD）
6. 熟悉现代前端工程化工具（Webpack / Vite / Metro / CI）
7. 良好的代码设计能力和编码规范意识
8. 复杂业务系统、实时交互、高性能场景经验（优先）
9. 较强的学习能力、问题解决能力及团队协作能力

### 面试流程

- 两轮技术面，中文
- 一面有 coding（easy-medium，practical coding 为主，可能考算法但看 foundation，不会太为难）
- 准备重点：刷题 + 梳理项目

好消息 Orbit Labs来邀请面试了 麻烦你提供一下最近方便的时间（越快越好） 一共是两轮技术面，中文面试，一面会有coding 一般是easy-medium的难度～

他们一般就算是考coding 也是practical coding    也有可能考察算法，但也是为了看看你的foundation那种，不会太为难你~但是需要你好好刷题，梳理好项目~

3. 跨端方案（RN / Flutter / Hybrid）经验
