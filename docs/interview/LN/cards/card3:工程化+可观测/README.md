# Card 3: 工程化 + 可观测

> 核心能力：大前端工程化全链路 — 代码规范 → CI/CD → 可观测 → 性能优化

---

## 核心叙事

大前端工程化体系的**建设者**：从代码规范 → CI/CD → 可观测 → 性能优化，全链路质量闭环。

---

## 关键技术点

| 维度 | 内容 |
|------|------|
| 可观测体系 | 稳定性 / 性能体验 / 内存 / 包体 / 人效 / 质量 六维度 |
| 构建体系 | Gradle / Xcodebuild / CMake / Vite，多端统一 CI 流水线 |
| 代码质量 | ESLint + Git Hooks + CI/CD 全链路卡控 |
| 包体优化 | R8 压缩混淆 + 条件编译 + 模块裁剪（153MB → 60MB） |
| 性能探针 | 秒开率 SDK（有限状态机 + AOP 注入测速） |
| 产物化集成 | Flutter AAR/Framework 独立编译，非 Flutter 开发无感接入 |

---

## 技术对照

| 岗位能力要求 | 切入点 |
|-------------|--------|
| 前端工程化 | 携程全链路卡控方案（编码 Lint → Hooks → CI/CD）|
| 构建/组件设计 | Flutter 产物化 + 条件编译工具套件（npm 开源） |
| Demo 快速交付 | 脚手架 CLI + CI/CD 流水线支撑快速迭代 |
| 独立工作能力 | 负载分析平台从 0 到 1 全栈独立交付 |
