- 轻卡交互 事件
快应用轻卡仅支持组件的通用事件 click，以及表单组件的 change 事件。对于事件的响应动作需要在 data 模块下 actions 下提前声明。

<template>
  <div>
    <!-- 正常格式 -->
    <text onclick="onTextClick"></text>
    <!-- 缩写 -->
    <text @click="onTextClick"></text>
        <!-- 正常格式 -->
    <input type="radio" checked='true' name="radioSample" value="radio1" onchange="onRadioChange"></input>
    <!-- 缩写 -->
    <input type="radio" checked='true' name="radioSample" value="radio1" @change="onRadioChange"></input>
  </div>
</template>
data 中的事件定义

<data>
{
  "actions": {
    "onTextClick": {
      "type": "router",
      "url": "hap://app/com.example.quickapp/page",
      "params": {
      	"param": "111"
      }
    },
    "onRadioChange": {
      "type": "message",
      "params": {
      	"checked": "{{$event.checked}}"
      }
    }
  }
}
</data>
快应用轻卡当前支持的事件响应动作有跳转（router）和消息（message)以及代理事件（proxy），事件响应动作格式定义如下：

参数	类型	必填	描述
type	"router" | "message" | "proxy"	是	事件类型：
router：跳转事件，直接在宿主侧完成。
message：消息事件，通过 onCardEvent 发送消息内容给提供方处理。
proxy：代理事件，用于自定义子组件代理到父组件的事件，当子组件事件被触发时便会触发父组件的事件。
url	String | Array	否	当事件类型为 router 时，必填，用于描述落地页链接，支持单条 rul 和多条 url，支持变量。当事件为 message 时，不需要。手表端不支持 Array
params	Object	否	事件支持携带的参数，参数中可以使用变量{{}}，只支持一级结构中绑定变量。
method	String	否	组件自定义事件名，当事件类型为 proxy 时生效。
#跳转事件(router)
跳转事件是可以直接在卡片宿主里完成跳转动作, 示例如下：

<data>
{
  "uiData": {
    "pageUrl": "hap://app/com.example.quickapp/page"，
    "a": "value_a",
    "b": "value_b",
  },
  "actions": {
    "routerEvent": {
      "type": "router",
      "url": "{{ pageUrl }}",
      "params": {"a" : {{a}}, "b":"b"， "c":{"s":"sss"}}
    }
  }
}
</data>
#支持跳转的 url 协议：
deeplink 协议
{scheme}://{host}/{path}?{query}
intent 协议 手表不支持
intent:#Intent;package={package};component={component};action={action};scheme={scheme};end
android-app 协议 手表不支持
android-app://{package}[/{scheme}[/{host}[/{path}]]][#Intent;component={component};action={action};scheme={scheme}]
#示例
任何 Activity 的都可以用以上三种协议 Uri 来描述

<activity android:name=".DeeplinkTestActivity">
    <intent-filter>
        <action android:name="android.intent.action.VIEW" />
        <category android:name="android.intent.category.DEFAULT" />
        <category android:name="android.intent.category.BROWSABLE" />
        <data
            android:host="deeptest"
            android:scheme="test"
            android:path="/index"/>
    </intent-filter>
</activity>
deeplink 协议
test://deeptest/index?key=1
intent 协议 手表不支持
intent:#Intent;component=cn.test.jumptest/.OpenClickActivity;end
android-app 协议 手表不支持
android-app://cn.test.jumptest#Intent;component=cn.test.jumptest/.OpenClickActivity;end
#消息事件(message)
消息事件是指事件发送给卡片提供方处理。

<data>
{
  "uiData": {
    "pageUrl": "hap://app/com.example.quickapp/page"
  },
  "actions": {
    "messageEvent": {
      "type": "message",
      "params": {"a" : {{a}}, "b":"b"， "c":{"cc":"}}
    }
  }
}
</data>
#代理事件(proxy)
代理事件，用于自定义子组件代理父组件中定义的事件，当子组件事件被触发时便会触发父组件的事件。

// 子组件
<template>
  <div class="tutorial-page" onclick="handleClick">
    <text class="tutorial-title">子组件</text>
  </div>
</template>

<style lang="less">
  .tutorial-page {
    flex-direction: column;
    padding-top: 20px;

    .tutorial-title {
      font-weight: bold;
    }
  }
</style>

<data>
{
  "actions": {
    "handleClick": {
      "type": "proxy",
      "method": "evt1"
    }
  }
}
</data>

// 父组件
<import name="comp-part1" src="./part1"></import>

<template>
  <div class="tutorial-page">
    <text class="tutorial-title">父组件：</text>
    <comp-part1
      @evt1="handleEvt1"
    ></comp-part1>
  </div>
</template>

<style lang="less">
  .tutorial-page {
    flex-direction: column;
    padding: 20px 10px;

    .tutorial-title {
      font-weight: bold;
    }
  }
</style>

<data>
{
  "uiData":{
    "jumpHomeUrl": "xxxxxx"
  },
  "actions": {
    "handleEvt1": {
      "type": "router",
      "url": "{{jumpHomeUrl}}"
    }
  }
}
</data>
