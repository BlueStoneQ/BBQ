# 职位描述

负责 Android 平台上基于 W3C 标准的自绘渲染引擎研发。引擎同时支持声明式卡片和 JS 卡片，为动态内容提供组件、布局、渲染、事件和脚本执行能力，渲染结果要与浏览器保持一致。

# 工作职责

1. 负责自绘渲染引擎的架构设计、核心开发和性能优化。
2. 完善 DOM、CSS、Flexbox、事件、组件和文本渲染能力。
3. 建设 JS 卡片能力，包括 JavaScript 引擎集成、组件模型、生命周期和 Native Bridge。
4. 解决布局、字体和视觉效果与 W3C 标准及浏览器不一致的问题。
5. 负责 Rust、JavaScript、Dart 与 Android 之间的跨语言通信，以及稳定性治理。
6. 建设自动化测试、视觉回归和性能监控体系。

# 任职要求

1. 5 年以上渲染引擎、浏览器内核、动态化框架或客户端基础设施经验。
2. 精通 Rust，熟悉内存管理、多线程、异步编程及 FFI。
3. 深入理解 JavaScript，熟悉 JS 引擎、运行时机制或 Native Bridge。
4. 熟悉 Android 开发，了解 Flutter/Dart 者优先。
5. 熟悉 DOM、CSS、Flexbox、W3C 标准或浏览器渲染流程。
6. 具备优秀的架构设计、系统调试和性能优化能力。

# 加分项

1. 有动态卡片、JS UI 框架、小程序或 Hybrid 引擎经验。
2. 有 Chromium、WebKit、Servo、Kraken/WebF、Lynx 等引擎经验。
3. 熟悉 QuickJS、V8、JavaScriptCore 或 WebAssembly。
4. 熟悉 Skia、Android NDK/JNI、Taffy 或 Yoga。
