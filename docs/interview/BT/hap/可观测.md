## 总览
| 域 | 已有观测 |
|---|---|
| 启动/加载性能 | App 加载、App JS 加载、页面加载、首帧/页面渲染耗时 |
| 渲染性能 | UI 线程任务、RenderAction 线程、FPS、页面前进耗时 |
| JS 性能 | JS 线程任务耗时、Framework Profiler、CPU Profile |
| 内存 | `MemoryMonitor` 读取 Android PSS |
| CPU | `CpuMonitor` |
| 稳定性 | 页面错误、Runtime 错误、崩溃描述和堆栈、Feature 调用失败 |
| 体积/资源 | RPK 磁盘占用、App 磁盘使用量 |
| Feature/接口 | Feature 调用次数、耗时、结果、权限结果 |
| 路由/使用 | App 展示、页面访问、路由、外部调用 |
| 卡片 | 卡片安装、下载、卸载、创建和运行结果 |

## 性能域
| 指标 | 定义 | 测算方案 | HAP 数据 / 参考目标 |
|---|---|---|---|
| 启动耗时 | 从启动请求到首屏可见 | 记录启动起点与首帧呈现时间差；区分冷启动、热启动 | 未见；冷启动可先以 ≤2 秒为目标 |
| 页面加载耗时 | 页面加载开始到加载结束 | 对应阶段起止埋点，统计 P50/P95 | 未见；不能等同于首帧耗时，目标需按页面定义 |
| 帧率 FPS | 单位时间呈现的帧数 | HAP 有 `FpsMonitor`；结合帧时间采集 | 未见；60Hz 屏幕以接近 60 FPS 为目标 |
| 慢帧率 | 超出刷新周期预算的帧占比 | 统计帧耗时超过 `1000 / 刷新率` 的比例 | 未见；60Hz 每帧预算约 16.7ms |
| UI/JS/渲染任务耗时 | 各线程单次任务占用时间 | HAP 有线程任务起止埋点；统计 P50/P95/最大值 | 未见；UI 工作应尽量留在帧预算内 |
| CPU 占用 | 进程消耗的 CPU 时间比例 | HAP 有 `CpuMonitor`；明确按单核还是整机归一化 | 未见；无通用阈值，应在固定场景、设备上比较 |
| JS 热点 | JS 函数的 CPU 时间分布 | Framework Profiler 导出 CPU Profile，查看火焰图 | 未见；主要用于定位热点，不设统一值 |
## 内存域
| 指标 | 定义 | 测算方案 | HAP 数据 / 参考目标 |
|---|---|---|---|
| 进程 PSS | 私有内存加按比例分摊的共享内存 | HAP `MemoryMonitor` 使用 `Debug.MemoryInfo.getTotalPss()` | 未见；无法脱离设备和页面给统一 MB 值 |
| 峰值内存 | 场景执行期间最大的内存占用 | 固定采样周期，记录启动、滚动、切页过程峰值 | 未见；以不触及目标设备内存预算为准 |
| 页面内存增量 | 新建页面带来的额外内存 | 稳定后 PSS 减去打开页面前基线，多次重复 | 未见；建议与同类原生页面对照 |
| 内存泄漏/残留 | 页面销毁后仍未释放的非预期对象 | 重复进入退出页面，结合 Java/Native/JS 堆分析 | 未见；目标是预热后不持续增长 |
## 包体
| 指标 | 定义 | 测算方案 | HAP 数据 / 参考目标 |
|---|---|---|---|
| APK/AAR 体积 | 平台及运行库的构建产物大小 | 按相同 ABI、构建模式统计产物，并拆分 DEX、SO、资源 | 未见；无通用阈值，建议做版本增量预算 |
| RPK 体积 | 业务包压缩后的大小 | 统计 RPK 文件字节数及 JS、图片、字体占比 | 未见；按业务复杂度制定预算 |
| 应用磁盘占用 | 应用资源及相关存储占用 | HAP 有 `logAppDiskUsage()`；精确目录范围需继续核对 | 未见；应与包体大小分开统计 |
| 缓存增长 | 持续使用带来的缓存增量 | 固定使用场景前后统计目录大小，验证清理策略 | 未见；目标是有上限、可回收 |
## 稳定性域
| 指标 | 定义 | 测算方案 | HAP 数据 / 参考目标 |
|---|---|---|---|
| 崩溃率 | 发生崩溃的会话数 / 总会话数 | HAP 有错误与堆栈埋点；需配合会话统计与去重 | 未见；可先以无崩溃会话率 ≥99.9% 为目标 |
| ANR 率 | 发生 ANR 的会话数 / 总会话数 | 系统 ANR 数据或专用监控；未确认 HAP 自带完整采集 | 未见；建议越接近零越好，口径需固定 |
| 页面错误率 | 页面加载或执行失败次数 / 页面访问次数 | 页面错误埋点关联页面访问，区分失败类型 | 未见；关键页面成功率可先定 ≥99.9% |
| Feature 失败率 | 非预期失败调用数 / 总调用数 | 根据 Feature 调用结果统计，排除用户取消等预期结果 | 未见；按能力分别定目标 |
| 长时间运行稳定性 | 持续运行是否出现崩溃、卡死、资源累积 | 循环切页、滚动、调用接口的耐久测试 | 未见；可先设置 24 小时无非预期退出的验收目标 |
## 功耗域
| 指标 | 定义 | 测算方案 | HAP 数据 / 参考目标 |
|---|---|---|---|
| 场景能耗 | 完成固定操作消耗的能量 | 功率仪或设备支持的电量计，积分得到 mWh/J | 未见自有体系；与原生基线对照，无统一绝对值 |
| 平均功率 | 场景期间单位时间能耗 | 总能量 / 场景时长；固定亮度、网络、温度 | 未见；比较同设备同场景 |
| 后台耗电 | 应用退后台后的额外能耗 | 固定待机时长，对照无应用运行的基线 | 未见；无后台任务时应接近基线 |
| 唤醒与持锁 | 后台唤醒次数、WakeLock 持有时间 | Android 系统电池统计、Perfetto 等工具 | 未见；无业务需求时应避免持续唤醒/持锁 |
