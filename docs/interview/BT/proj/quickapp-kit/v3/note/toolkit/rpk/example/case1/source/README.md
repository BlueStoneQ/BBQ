# QuickApp Kit V1 Golden App

This is the V1 integrated baseline for the QuickApp Kit runtime.

## Coverage

- Home and Detail pages
- Reactive state update
- Conditional `if` rendering
- Keyed `for` list reorder
- Click event dispatch
- `router.push()` and `router.back()`
- Page lifecycle and teardown

## Source

The source is alliance-compatible QuickApp DSL under `src/`. The runtime must
consume the RPK produced by Toolkit; it must not use hand-written Page IR or
runtime transactions.

## LVGL verification

From `quickapp-examples/`:

```text
cmake --build build-m1-s2 -j 4
SDL_VIDEODRIVER=dummy ./build-m1-s2/quickapp_case001_lvgl --lvgl-p0
```

The current deterministic RPK is generated by the Toolkit integration build:

```text
quickapp-toolkit/evidence/tk-s12-lvgl-p0.rpk
```

The expected path is:

```text
Home -> state/if/keyed for -> Detail -> router.back() -> Home -> teardown
```

Focused regression fixtures remain in the sibling `alliance-hap-case001` through
`quickapp-code-test4` directories and are not replaced by this application.
