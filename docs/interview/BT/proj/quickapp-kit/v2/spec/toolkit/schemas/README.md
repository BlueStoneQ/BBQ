# Toolkit Schema Registry

V1 Schema：

| Schema | 对应合同 |
|---|---|
| `template-ir.schema.json` | Template IR |
| `binding-metadata.schema.json` | Binding Metadata |
| `block-ir.schema.json` | Block IR |
| `handler-metadata.schema.json` | Handler Metadata |
| `style-ir.schema.json` | Style IR |
| `runtime-meta.schema.json` | Runtime Metadata |
| `package-index.schema.json` | Bundle/Chunk Package Index |

所有 Schema 使用 JSON Schema 2020-12，`schemaVersion: 1` 对应 V1 合同。
