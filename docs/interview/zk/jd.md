## 原文

- **岗位**：全栈工程师
- **薪酬**：60-80 万
- **Base**：杭州

### 职位描述

1. 深度参与新一代 AI-Native 工业软件的核心研发，探索 AI Agent 在工业场景的可能性
2. 全栈无界：负责技术选型、架构设计，从数据库到前端界面，全程主导
3. 架构优化：设计高可用系统，持续性能调优，保障数据安全与系统稳定性
4. 项目协作：和产品/设计协作，快速落地，持续迭代
5. 紧盯 AI 前沿（LLM、Agentic Workflow、Claude Skills 等），打造下一代 AI-Native 研发效能解决方案
6. 从零到一搭建支持 AI 开发的基础设施，重新定义开发者体验

### 职位要求

1. 研究生及以上学历，3 年以上全栈开发经验。对计算机底层、系统架构有深入理解
2. 具备全栈开发能力，至少精通一门语言，快速上手新语言
3. 对研发工具链、开发流程有深刻的实践和优化经验
4. 深度研究过 AI Coding 工具（Cursor、Windsurf、GitHub Copilot 等），对 AI Agent 产品有热情
5. 熟悉主流 Agent 框架和上下文工程技术栈，有 Agent 架构、CodeRAG 等实战经验
6. 极度好奇、执行力强，逻辑清晰、表达流畅
