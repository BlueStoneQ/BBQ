# AI Coding 可观测指标

> AI 辅助开发的效果怎么衡量？纳入可观测体系。

---

## 效果 Top3 指标

| # | 指标 | 怎么算 | 基准 |
|---|------|--------|------|
| 1 | **AI 代码采纳率** | 被 accept 的 AI 生成代码行 / AI 总生成行 | > 60% 算有效 |
| 2 | **需求交付周期缩短比** | (传统周期 - AI 辅助周期) / 传统周期 | 目标 30-50% |
| 3 | **AI 生成代码缺陷率** | AI 生成的代码引入的 bug 数 / AI 生成总 PR 数 | 应 ≤ 人工水平 |

## 设计稿一致性保障

| 层 | 手段 | 说明 |
|----|------|------|
| 约束层 | Figma MCP → 提取设计 token | AI 生成代码时以 token（颜色/间距/字号）为约束 |
| 自动验证层 | 截图对比（视觉回归） | CI 跑 Playwright 截图 → 和设计稿逐像素 diff(py和playwrite就能做到) → 差异 > 5% 阻断合并 |
| 人工兜底层 | 设计师 Review | PR 中 Review UI 截图（Storybook / 预览环境） |
