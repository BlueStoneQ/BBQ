# 岗位职责

1. 负责移动端大模型应用 APP 的研发工作，参与 iOS/Android 跨端产品从 0 到 1 的架构设计、核心功能开发、上线迭代与体验优化；
2. 围绕 AI 对话、翻译、总结、写作辅助、多轮会话、语音输入/播报、文档处理等场景，完成大模型能力在移动端的产品化落地；
3. 负责 APP 与大模型服务的接入与优化，包括流式输出、上下文管理、会话历史、Prompt 模板、模型路由、请求重试、缓存、弱网/无网处理等能力建设；
4. 参与端侧大模型能力探索，支持模型文件下载与管理、端侧推理接入、量化模型运行、离线能力、隐私保护、首 Token 延迟、内存与功耗优化等工作；
5. 建设高质量移动端工程体系，保障 APP 在多端设备上的稳定性、兼容性、性能、安全性和用户体验；
6. 与产品、算法、服务端、设计团队紧密协作，持续打磨面向 C 端用户的 AI 原生应用体验，打造好用、稳定、智能的移动端大模型应用。

# 岗位要求

1. 本科及以上学历，计算机、软件工程、人工智能等相关专业优先，3 年以上移动端 APP 开发经验，有复杂 C 端应用或 AI 应用从 0 到 1 经验优先；
2. 熟练掌握 iOS 或 Android 原生开发，熟悉 Swift/Objective-C、Kotlin/Java 中至少一种技术栈，具备良好的移动端架构设计和工程落地能力；
3. 熟悉 Flutter、React Native、Kotlin Multiplatform、腾讯 Kuikly 等跨端开发方案中的一种或多种，能够保障 iOS/Android 多端体验一致性和交付效率；
4. 熟悉移动端常见工程能力，包括组件化/模块化、状态管理、网络通信、本地存储、权限管理、推送、埋点、灰度发布、版本升级等；
5. 具备扎实的性能与稳定性优化经验，能够独立处理启动速度、包体积、内存占用、卡顿、耗电、Crash/ANR、弱网、兼容性等问题；
6. 熟悉大模型应用开发链路，理解多轮对话、上下文窗口、Token 消耗、流式响应、Prompt 编排、模型 API 接入、模型降级/路由、内容安全等能力。

# 加分项

1. 有端侧模型部署与推理经验为加分项，如使用 llama.cpp、GGML/GGUF、MLC-LLM、ONNX Runtime Mobile、TensorFlow Lite、Core ML、MNN、NCNN 等框架在移动端部署 LLM、翻译、ASR、OCR、Embedding 等模型；
8. 了解模型量化、KV Cache、推理加速、Metal/Vulkan/NNAPI/GPU/NPU/DSP、模型动态下载与版本管理、离线推理、端云协同等方向者优先；
2. 另外具备 HarmonyOS 或小程序应用开发或上架经验者优先；
3. 具备良好的产品意识、用户体验意识和技术责任心，能够主动与产品、算法、后端团队协作，推动 AI 能力在移动端高质量落地。
