# 岗位职责

1. 负责 WorkBuddy 桌面端（Electron）核心业务功能的设计与开发，将产品需求高质量落地为稳定可用的桌面体验；
2. 负责客户端业务的领域建模与架构抽象，将复杂产品诉求转化为清晰的业务分层、模块边界与可扩展实现方案；
3. 主导跨平台（Windows/macOS/Linux 及信创）业务功能适配，保障各系统在功能与体验上的一致性与完整性；
4. 与产品、设计、AI Agent 团队紧密协作，承接复杂业务场景（Agent 任务执行、本地文件操作、多任务并行）的客户端实现；
5. 持续优化桌面端交互体验与可用性，打磨细节，提升用户在日常办公与开发场景下的使用流畅度；
6. 沉淀客户端业务组件与开发规范，跨团队复用能力、拉通桌面端技术标准。

# 岗位要求

1. 5 年以上客户端研发经验，精通 TypeScript/JavaScript，有 Electron 或 C++/Rust/移动端客户端开发经验，具备原生模块集成能力者优先；
2. 有 Windows/macOS/Linux 及信创（统信 UOS、麒麟等）跨平台桌面开发经验，能独立交付完整业务功能；
3. 具备良好的业务架构思维与抽象能力，能将复杂产品需求拆解为清晰、可扩展的客户端实现方案；
4. 有 iOS 或 Android 原生开发背景者优先，移动端经验可平移至桌面端架构设计与业务实现；
5. 具备突出的问题定位与攻坚能力，面对疑难缺陷能深入根因、跨层排查并推动彻底解决；
6. 在同等条件下，通过腾讯云认证或取得同等资格认证的候选人，我们会优先考虑。
