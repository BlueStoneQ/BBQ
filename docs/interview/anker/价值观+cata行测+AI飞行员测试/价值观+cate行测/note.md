## 三大价值观（选题唯一标准）

| 价值观 | 核心含义 | 选什么 | 不选什么 |
|--------|---------|--------|---------|
| **第一性** | 抛开表面事实和经验，回归基础原理，找到问题本质和突破方向 | 追问根因、重新审视方向、从用户本质需求出发、不跟风 | 照搬经验、人云亦云、只看表面数据、走捷径 |
| **求极致** | 顶着风险、想尽办法，追求长期全局最优解；走"第一性小道" | 高标准、直面冲突、敢做没人做过的事、创造性而非改良 | 妥协、"差不多就行"、只盯竞争对手模仿、回避困难 |
| **共成长** | 长期主义、自我进化、公心大局、价值分配匹配价值创造 | 团队共赢、延迟满足、持续学习、"先人后事" | 抢功、钻规则、短期KPI 导向、只顾个人利益 |

## 阳萌原话关键观点（帮助理解选项倾向）

### 第一性
- "抛开表面事实，回归基础原理，找到突破方向"
- 马斯克电池例子：**别人说**电池 5 万美金不可能，他查原材料只需 5000 → 做大规模就能解决
- "超越客户本质需求" vs "超越同行" — Anker 明确放弃竞争思维，只追求从用户本质需求出发
- 贝索斯/乔布斯：伟大公司从不把竞争挂嘴边，而是痴迷于客户价值

### 求极致
- "第一性小道" — 没人走过的路，看起来不像路，可能有人死在半路
- 不是"超越同行"（那是收敛），是"创造全新赛道"（发散）
- 储能亏 6-7 亿坚持 3 年、扫地机亏 10 亿坚持 4 年 — 选定方向后极致投入
- 3D 打印团队失败后不解散 → 找新赛道 UV 打印 → 打破众筹记录

### 共成长
- "先人后事" — 找对人比做对事重要
- 劳动者 vs 股东 = 7:3 分配
- "价值分配必须匹配价值创造，否则价值创造就不能持续"（任正非）
- 不因一两次失败放弃高价值观的人 — 愿意交学费
- "腾笼换鸟" — 走掉价值观不合的人，换上对的人

## 考试选题口诀

1. **每题用三个价值观做筛子** → 哪两个选项最符合 第一性/求极致/共成长 → 选它
2. **排除法** → 看到"走捷径/钻规则/只看眼前/推卸/回避冲突/模仿同行/差不多就行" → 不选
3. **冲突时**：长期 > 短期 / 本质 > 表面 / 团队 > 个人 / 创造 > 改良

## 高频场景判断

| 场景 | 选 | 不选 |
|------|---|------|
| 业绩不好怎么办 | 识别低效环节 + 重新审视方向 | 算计哪些业绩算自己的 / 钻奖金规则 |
| 竞品出了新产品 | 回归用户本质需求，找差异化方向 | 赶紧模仿跟进 |
| 项目遇到困难 | 顶着风险想办法突破 | 降标准/妥协/找借口 |
| 团队有人不行 | 直面问题，调整人员 | 回避冲突，维持表面和气 |
| 新业务机会 | 评估客户价值和商业价值，找对人再干 | 看到别人做就跟风 / 不思考直接铺人 |
| 分功劳/资源 | 公心大局，价值分配匹配贡献 | 抢功/只顾自己部门利益 |
| 失败了怎么办 | 复盘根因，保留高价值观团队，换方向再来 | 甩锅/解散团队/放弃 |

## 注意事项
- 这不是性格测试，有标准答案
- 不要"展现个性"，要对齐 Anker 价值观
- 如果两个选项都对，选更"第一性"的那个（本质 > 执行）
