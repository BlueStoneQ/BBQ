1. 智能体的5个层级
业界通常把智能体（Agent）根据智能化程度区分为5个等级，市面上的主流智能体技术正在从L1往 L2/L3过渡，今天介绍的主角，就是一个L2任务级智能体。
智能体等级
定义
典型场景
典型工具
L1 功能级

“AI对话工具”，按指令执行单步操作，无自主规划。

- 检索查询
- 简单案列报告
- 表格格式化
- 翻译
- ChatGPT
- DeepSeek
- 豆包
L2 任务级

Agent 能拆解并分配复杂任务，仍需外部流程驱动。

- 质检趋势分析
- 售后案例总结
- 自动生成模块代码
- 市场规模分析
- Claude Code
- Microsoft Copilot
- OpenAI o1集成Tools
L3 协同级

Agent 能自我规划并执行限定领域任务；人类主要负责协作与监督。
- 营销洞察到广告投放
- 软件产品设计到开发
- 质量问题发现到解决
- 软件领域的Spec-kit
- 营销领域的Agentforce
L4 指导级

Agent 具备专家级指导/服务能力，可在清晰边界内自主决策与持续运行；人类参与但不过度干预。


L5 智慧级

全面自治，跨领域泛化能力接近/超越人类；在授权框架下独立行事并对其它 Agent 进行编配。

4. 掌握基础用法
当你启动后，就进入了一个可以「和 AI 一起动手做事」的空间。
 这里没有复杂的界面，也不需要编程经验。它就像一个聪明的工作伙伴，你只要告诉它要做什么，它就能帮你一步步完成。
跟着我3步使用它完成第一个任务。
Step 1
学会和它对话
 操作方式非常简单：
- 像聊天一样输入你的任务；
- 它会根据上下文自动判断该做什么。
示例：
帮我读取 sales_data.xlsx，计算一下每个月的销售总额，并输出表格。
它会自动帮你：
1. 寻找文件
2. 打开/读取文件
3. 计算结果
4. 输出成表格或报告，也可以保存到桌面
✅ 你不用写代码，它会自动生成、执行并保存到文件夹中。
Step 2
学习常见的小指令
只是快捷键，直接自然语言对话效果也一样
- /model：可以切换AI模型，如需识别PDF文件请切换至Haiku模型。
-  /run ：运行自动生成的代码（执行任务）
- /todos：查看当前正在处理的任务清单
- /status：检查当前状态（是否联网、是否执行完毕）
- /rewind：回到上一步（撤销或重做）
- /rename：为当前会话命名，方便在历史列表中识别
- /resume：在交互式会话中切换到另一个历史会话
- /export<文件名>：将当前完整对话导出为Markdown文件保存
如果需要恢复历史会话，建议直接使用【终端】CLI命令
- /claude-c：继续最近的一次会话
- /claude-r：从历史会话列表中选择一个来恢复
Step 3
动手试一试
可以直接复制下面的句子，中执行看看：
请帮我创建一个名为 product_list.csv 的文件，
里面包含 5 个示例产品（名称、价格、库存），并生成一张表格。
它会自动：
- 创建文件
- 填好表格
- 输出到本地文件夹
小彩蛋：试试发送：“以后都用中文回复我”
恭喜！你完成了人生第一个智能体任务 。它的核心不是写代码，而是帮你执行任务。
 你只需要清楚地说出目标，它会自动思考「要做什么、怎么做、做到哪一步」。
🪶 一句话记住：
你定义目标，它执行任务。

5. 用AI助手完成能力提示及认证测试
现在你已经学会了AI助手的基本用法，接下来，我们要用它来完成属于你的第一次 AI 测评 🚀。
它将陪你一起完成一个完整的任务闭环。
📊 Insight（洞察） → 🎯 Strategy（策略） → ⚙️ Operation（执行）
步骤
输入
给出输出
小技巧
Step 1：
Insight 
 不只是执行命令，它能帮你分析、归纳和总结。
你可以向它提出一个探索性问题，比如：
“请帮我阅读这些用户评论，提炼出主要的痛点和改进方向。”
它会自动：
- 从文本中提取关键信息（如用户痛点、情绪关键词）
- 进行聚类和对比分析
- 输出清晰的洞察结论
- 尽量给一批原始材料（如用户评价、市场评论、数据表格）
- 告诉它你想得到什么形式的结果（如“表格总结”或“要点清单”）
Step 2：
Strategy 
当洞察阶段结束后，它会帮你把“发现的问题”转化为“行动策略”。
你可以这样开始：
“根据上一步分析的结果，请帮我梳理产品策略，包括目标用户、核心价值、关键功能和风险点。”
它会引导你完成：
- 产品/项目目标的结构化整理
- 优先级排序与资源分配建议
- 风险点识别与备选方案
- 如果给出的方案太笼统，可以要求它“以表格形式总结”或“只保留重点五项”
- 你可以让它生成“策略摘要”用于汇报或会议材料

Step 3：
Operation 
最后一步，就是把策略转化为可交付成果。
它能帮你：
-  生成报告、方案、脚本或表格
- 输出可以直接使用的文本、文件或网页
你可以这样尝试：
“请根据上面的策略，生成一份可执行的行动计划表，包括负责人、时间节点和验收标准，并制作成一个方便阅读的网页。”
它会自动：
1. 生成结构化表格（任务 + 负责人 + 时间 + 状态）
2. 保存为 .csv 或 .xlsx 文件
3. 制作可运行的网页
4. 提供执行日志与进度反馈

当然，AI也不是万能的，还是需要你来做最后的判断和把控哦！

Q1：我听说要“招飞”，是不是很神秘的考核？
- 其实一点也不神秘！“AI飞行员试炼”是安克创新在所有面试流程中设立的线上挑战环节，重点考察你面对实际业务场景时运用AI解决问题的能力。进入提供的在线平台后，你需要使用已提供和搭建好的AI工具，在规定时间内完成问题分析、方案设计，并提交具体成果。这是一次真实的“职场实战体验”。

Q2：试炼通过后，是否还需要参加其他环节？
- 「AI 飞行员试炼」是各位通往安克的“加速器”：试炼成绩优异的同学将获得加速特权。

Q3：我不是技术岗也能参加吗？
- 完全可以！职能类同学也有对应的场景，更注重你的问题分析和解决能力，而不是代码功底。很多非技术背景的同学都在首批试炼中拿到了高分。AI时代下，这已经不是程序员的专属工具了，而是每一个人的“超级助手”！

Q4：这个环节和传统面试有什么不同？
- 传统面试主要考察“你知道什么”，而“AI飞行员试炼”是结合真实业务场景，通过AI工具和你的自主探索来完成解决问题的任务，更关注“你怎么思考、能否快速学习、如何借助AI把方案落地”。它主要考察的是你的思维力、学习力和创造力，这也正是安克未来最看重的职场能力。
