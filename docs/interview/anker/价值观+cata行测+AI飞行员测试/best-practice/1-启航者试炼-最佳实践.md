# ① 启航者试炼（价值观）— 最佳实践

> 20 题 / 30 分钟 / 四选二 / 有标准答案

---

## 本质

**不是性格测试，是价值观对齐测试。有标准答案。** 选项和 Anker 三大价值观对齐的就选，不对齐的就不选。不要"展现个性"。

---

## 大纲（3 条）

1. **每道题用三个价值观做筛子**：哪两个选项最符合第一性/求极致/共成长 → 选它
2. **排除法**：选项里有"走捷径/钻规则/只看眼前/推卸/回避冲突"→ 不选
3. **冲突时选长期 + 本质 + 团队**：短期 vs 长期 → 选长期；表面 vs 本质 → 选本质；个人 vs 团队 → 选团队

---

## 总览

| 价值观 | 关键词 | 选什么 | 不选什么 |
|--------|--------|--------|---------|
| **第一性** | 回归本质 / 抓关键 / 不被表象束缚 | 追问根因、重新审视方向、结构化分析 | 跟风、照搬经验、不思考直接执行 |
| **求极致** | 顶着风险 / 想尽办法 / 长期全局最优 | 高标准、直面冲突、识别低效并改进 | 妥协、"差不多就行"、回避困难 |
| **共成长** | 长期主义 / 公心大局 / 自我进化 | 团队共赢、延迟满足、持续学习、感恩 | 抢功、钻空子、只顾自己利益 |

## 真题示例

> 接手 20 人团队，士气低，创新项目无成果，奖金受影响。选两项：
> A. 和周边团队计算哪些业绩属于本团队
> B. 研究奖金规则从公司多获取资源
> C. 识别低效环节和表现不佳员工，进行管理
> D. 重新审视研发方向和产品策略

**答案：C + D**
- C = 求极致（直面冲突，抓关键）
- D = 第一性（回归本质，重新审视方向）
- A = ❌ 引发团队冲突（违反共成长）
- B = ❌ 钻规则漏洞（违反第一性/大局为先）
