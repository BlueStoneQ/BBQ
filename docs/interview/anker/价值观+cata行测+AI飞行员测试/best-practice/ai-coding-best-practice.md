# AI Coding 解决问题最佳实践

> 本质：你是决策者，AI 是执行者。你定方向 + 质检，AI 出活。

---

## 大纲（3 条）

1. **一次一件事**：每轮对话只给一个清晰任务，不一次性甩 10 个需求
2. **分角色驱动**：不同任务给 AI 不同身份（分析师/开发者/检查者），输出质量更高
3. **质疑 + 迭代**：每 3-5 轮必须有一次显式质疑或纠偏，不全盘接受

---

## 速查表

| 环节 | Prompt 策略 | 示例 |
|------|------------|------|
| **定义任务** | 角色 + 背景 + 具体要求 + 输出格式 | "你是资深产品经理，帮我拆解这个需求，输出 markdown 表格" |
| **生成方案** | 要求多方案 + 对比 + 推荐 | "给 2-3 个方案，说明 trade-off，推荐一个" |
| **写代码** | 指定技术栈 + 限定范围 + 禁止项 | "用 React + Tailwind，只做首页，不要引入新依赖" |
| **质疑** | 指出具体问题 + 要求改进方向 | "这里没有 error handling，补上；这个算法复杂度太高" |
| **检查** | 让 AI 换角色自审 | "现在你是严格的 code reviewer，找出上面代码的 3 个问题" |
| **外部信息** | 让 AI 搜索补充 | "用你的知识库补充这个行业的 benchmark 数据" |

## 关键原则

- **不要一次性喂太多**：拆成 30+ 轮小对话 > 3 轮长对话
- **控制输出格式**：要求 AI 输出 md/json/html，不要纯文字
- **及时保存**：每个阶段让 AI 把结果写入文件，不只是对话框里
- **切模型**：如果默认模型太慢/太蠢，`/model` 切 opus
- **多窗口**：不同任务开不同终端窗口并行，避免上下文撑爆
