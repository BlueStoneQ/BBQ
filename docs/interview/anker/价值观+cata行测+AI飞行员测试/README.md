## ① 启航者试炼（价值观）

**形式**：20 道题，每题 4 个选项选 2 个，30 分钟。

**选题依据**：Anker 三大价值观，阅读测评邮件里的两篇文章后作答。

### Anker 三大价值观

| 价值观 | 关键词 | 选题方向 |
|--------|--------|---------|
| **第一性** | 抛开表面事实 → 回归基础原理 → 抓住关键突破 | 选"追根溯源/简化问题/找本质"的选项 |
| **求极致** | 顶着巨大风险 → 想尽一切办法 → 长期全局最优 | 选"不妥协/高标准/长期收益"的选项 |
| **共成长** | 长期主义 + 延迟满足 + 终局思维 + 公心大局 + 持续学习 + 自我察觉进化 | 选"团队优先/自我反思/愿意投入时间"的选项 |

### 选题策略

- 每道题 4 选 2，选**最符合上述三个价值观**的两个
- 遇到"短期利益 vs 长期收益"→ 选长期（求极致 + 共成长）
- 遇到"表面方案 vs 追问本质"→ 选追问（第一性）
- 遇到"个人表现 vs 团队共赢"→ 选团队（共成长）
- 不要选"走捷径/妥协/只看眼前"的选项

## ② CATA 北森（行测）

**形式**：阅读理解 + 数学计算 + 图形规律，限时。

| 题型 | 考什么 | 准备建议 |
|------|--------|---------|
| 阅读理解 | 快速提取关键信息 | 先看问题再读文章，定位关键句 |
| 数学计算 | 速算 + 数据推理 | 练习百分比/增长率/比例计算 |
| 图形规律 | 逻辑推理 + 空间思维 | 找旋转/对称/叠加/递推规则 |

**CATA 特点**：北森的自适应测试（Computer Adaptive Testing），答对难度升、答错难度降。前几题很关键（决定起始难度）。

**建议**：三个测试任何一个不过都会被卡。CATA 同样认真对待，前几题决定段位，不能随便做。

## ③ AI 飞行员试炼

→ [专题准备文档](./ai-coding.md)

**形式**：
- 正式测评前有详细文档和视频教程
- 需提前下载软件（OpenCode）
- 正式前有 30min 熟悉时间
- 正式 3h：给定场景，用 AI（Claude）协作完成项目

**评分重点**：不只看结果，看你**和 AI 协作的过程**——是否体现架构思维、质疑能力、方案决策力。

**核心**：Claude 会根据你整个交互过程给出评分。
