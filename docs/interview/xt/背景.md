# 深圳xTool（制具工坊，激光雕刻切割机，软件：旧版XCS / 新版xTool Studio）桌面端 + CAD/刀路选型
> 注意：它**不是通用工业CAD/CAM软件**，属于**激光前置排版+路径规划软件**，对标LightBurn，不是UG、Mastercam；只做2D矢量+位图，**没有3D实体CAD内核**（它的“3D曲面雕刻”是图片映射到旋转曲面，不是实体建模）。

## 一、桌面端技术选型（XCS → xTool Studio两代）
### 旧版 XCS（xTool Creative Space，D1/M1/P2早期配套）
- 主框架：**Electron（Chromium + Node.js）**，前端Web技术栈（Vue），跨平台Windows/macOS。
- 重计算模块（矢量布尔、图像矢量化、填充扫描、路径优化、G代码生成）：**C++原生底层模块（Node Addon）**，打包进Electron。
- 画布渲染：Canvas / WebGL。
- 通信层：Node.js，USB/HID + Wi-Fi（TCP/UDP），局域网设备发现。
- 存储：本地JSON项目文件 `.xcs`；云同步走后端HTTP。

### 新版 xTool Studio（P3/F2 Ultra起，接替XCS）
架构延续Electron大框架，但**大幅重构C++底层内核包**：
- UI层：Electron + Vue3，WebGL画布，升级大矢量渲染性能、嵌套排版、AI图像抠图。
- 核心计算层独立C++库：**矢量解析、布尔、偏移、填充扫描、图像矢量化、路径排序、G-code生成**，作为原生插件。
- AI能力：AI图像识别、图转矢量，部分推理在本地C++，云端生成（AImake）。
- 项目文件：新版 `.xtool` 工程格式。

> 业界逆向+招聘信息佐证：前端Electron/Vue，**几何/路径 heavy 计算下沉C++**，不是纯前端。
> ❌ 不是Qt，不是WPF；这点和寻天XT Solution完全不一样。

## 二、CAD矢量内核（它没有工业BRep实体CAD！）
xTool只处理**2D平面矢量（SVG/DXF）**，**无OpenCASCADE、Parasolid这类三维实体几何内核**。
1. 2D矢量几何库：**自研2D几何内核（C++）**
    - 能力：SVG/DXF解析、贝塞尔曲线、多边形布尔（合并/减去/相交）、轮廓偏移offset、路径合并、曲线平滑。
    - 位图矢量化（Trace Image）：自研边缘提取算法，把图片转矢量轮廓。
    - 没有草图约束、参数化实体、3D BRep。
2. DXF/SVG解析：自研解析器，新版Studio新增独立高精度DXF解析开关。

> 一句话区分：LightBurn逻辑一样——**2D矢量几何库 ≠ 工业三维CAD内核**。

## 三、CAM/激光刀路（路径规划）选型
同样**没有通用工业CAM内核（非ModuleWorks/MachineWorks）**，是面向激光切割/雕刻自研2D路径生成器（C++）：
1. 两类路径：
    - **切割路径（Cut/Score）**：矢量轮廓线，轮廓排序、最短路径优化（减少激光头空走）。
    - **雕刻填充路径（Fill/Raster）**：自研扫描填充算法，支持单向/双向、偏移环绕填充Offset fill、斜向填充、渐变灰度位图点阵扫描；新版本大幅优化填充效率。
2. 输出：内部直接生成xTool机器原生运动指令，也可导出标准G-code兼容LightBurn。
3. 曲面3D雕刻（Rotary旋转轴雕刻）：**不是3D CAM**，是把2D图片/矢量做UV映射投影到回转曲面，运动插补还是2.5D平面路径映射，不做实体等距、曲面刀路。
4. 嵌套排料Nesting：新版Studio内置自研智能排料算法（标准/紧凑/矩阵模式）。

## 四、整体架构分层
1. UI层：Electron + Vue3 + WebGL（画布预览、图层、属性面板）
2. 业务层：NodeJS，项目管理、设备通信、云同步、参数库
3. 核心计算层（C++ Native Addon）：
    - 2D矢量几何引擎（布尔、偏移、曲线）
    - 图像矢量化 & 位图灰度采样
    - 激光路径规划/填充/排序（激光CAM）
    - Gcode/设备指令生成
4. 硬件通信：TCP/WiFi / USB HID，下发运动指令、读取摄像头图像、回传设备状态

## 五、一句话总结
深圳xTool桌面软件（XCS/xTool Studio）：**Electron+Vue3做UI，Heavy几何/路径算法C++原生插件；CAD是自研2D矢量几何库（无三维BRep内核）；CAM是自研2D激光专用路径生成器，没有外购商用CAM库（ModuleWorks等）**。
