# 岗位职责

- 负责移动端跨端技术体系建设与落地，覆盖 Flutter / React Native / 小程序容器 / WebView 容器等方向，提升多端体验一致性与业务交付效率。
- 设计并演进跨端混合栈架构，支撑业务扩展性，包括页面路由、状态管理、原生桥接、组件库、设计系统与模块化拆分。
- 主导跨端性能、体验与稳定性治理，包括但不限如建立启动、帧率、卡顿、Crash、ANR、包体积、发版成功率等北极星指标与防劣化机制。
- 建设跨端工程效能体系，包括脚手架环境工程、CI/CD、自动化测试与灰度发布能力等。
- 推进核心业务端框架到跨端化改造，平衡业务交付速度、代码质量、原生能力与长期维护成本。
- 联动业务应用端 iOS/Android 原生、前端、服务端、QA、产品等团队，制定技术标准、
- 负责跨端相关线上问题定位与复盘，建立监控、告警、回滚和事故闭环机制。
- 承担端架构、Infra、体验、性能方向的技术团队梯队建设和管理
- 参与制定泛前端技术标准、指标目标等建设。
- 参与制定泛前端 AI 工程能力建设，

# 任职资格

1. 本科及以上学历，计算机科学、软件工程、信息技术等相关专业；
2. 7 年及以上相关工作经验；
3. 具备 iOS/Android 原生应用开发背景经验，对原生应用到混合跨端架构、发布、业务应用有较好积累和项目落地经验，具备性能、体验优化的丰富经验；
4. 具备 React Native、Flutter、小程序、KMP 等跨端、跨平台开发经验，主导或参与过大规模跨端项目落地，熟悉跨端容器、环境等建设；
5. 有跨平台引擎/框架层开发经验，主导过 RN 新架构或其他跨平台框架的实际业务落地，以及工程环境体系的搭建；
6. 具备良好的技术文档写作能力、沟通能力和 AI 工程能力；
7. 具备出色的技术领导力、决策能力、沟通表达能力、团队协作精神、问题分析解决能力、持续学习创新精神以及项目管理和资源协调能力；
8. 具备 AI Coding 以及 Agent 工程能力上应用。
