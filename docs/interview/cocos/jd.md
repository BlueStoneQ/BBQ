## 原始 JD

Base地：厦门、上海、北京均可！！！

【产品】
Pink编辑器是 vscode + cocos creator 的结合（游戏+代码编辑器），栈是electron(必备) 。

【职位亮点】
1、技术深水区： 深度定制 VSCode 源码，非应用层开发，挑战 IDE 底层逻辑。
2、前沿方向： 探索 AI Agent 与编辑器深度融合的工作流（MCP 协议、智能补全）。
3、跨界融合： 结合 Cocos Creator 引擎能力，打造下一代"游戏 + 代码"双驱动编辑器。

【岗位职责】
1、IDE 核心开发： 基于 VSCode-OSS 进行功能抽离与深度定制，优化编辑器内核及界面响应性能；
2、游戏引擎集成： 研发 Pink 编辑器核心模块，包括场景编辑器、资产管理系统（Assets）、节点树（Node Tree）及实时 Log 通讯机制；
3、AI 协同进化： 研发基于 LLM 的 AI 工作流插件，实现智能代码辅助、自动化资源处理等 Agent 协作功能；
4、底层性能优化： 优化维护 Electron 多进程设计、跨平台构建（Build/Release）流程及 Webview 与主进程的高性能通信。

【任职要求】
1、硬性背景： 计算机相关专业本科及以上学历，3 年以上编辑器或复杂桌面应用开发经验；
2、核心技术：
  - 精通 Electron 及其多进程模型，有实际的商业级跨平台项目上线经验；
  - 极强的 TypeScript 功底，熟悉 Node.js 异步编程优先；
  - 熟悉前端工程化，对 Canvas、WebGL 或 CSS 性能调优有深入理解。
3、源码理解： 熟悉 VSCode Extension API，有 VSCode 源码 阅读或二次开发经验者（如定制插件、LSP 协议等）优先考虑。

【加分项】
1、游戏开发经验： 熟悉 Cocos Creator、Unity 或 Unreal 引擎的底层工作原理。
2、社区贡献： 拥有开源编辑器插件项目，或为 VSCode、Electron 等知名开源库贡献过代码。
3、AI 领域： 熟悉 OpenAI API、Cursor 产品逻辑或有 MCP (Model Context Protocol) 协议集成经验。
